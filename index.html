A edição definitiva em Hyprland.



Se apenas uma parte baixar: Parte 1 (1,8 GB) · Parte 2 (1,5 GB)
1. Clique no botão acima para baixar as duas partes. Se o navegador perguntar, permita downloads múltiplos.
2. Abra o Terminal (Linux/macOS) ou o Prompt de Comando (Windows):
• Windows: aperte a tecla Windows, digite cmd e aperte Enter.
• Linux: aperte Ctrl + Alt + T.
• macOS: aperte Command + Espaço, digite Terminal e aperte Enter.
3. No terminal, entre na pasta onde os arquivos foram baixados:
• Linux/macOS: cd ~/Downloads
• Windows: cd %USERPROFILE%\Downloads
4. Cole o comando abaixo no terminal e aperte Enter para juntar as duas partes:
• Linux/macOS: cat ticoOS-BETA-v0.0.1-x86_64.iso.part1 ticoOS-BETA-v0.0.1-x86_64.iso.part2 > ticoOS-BETA-v0.0.1-x86_64.iso
• Windows: copy /b ticoOS-BETA-v0.0.1-x86_64.iso.part1+ticoOS-BETA-v0.0.1-x86_64.iso.part2 ticoOS-BETA-v0.0.1-x86_64.iso
5. O arquivo ticoOS-BETA-v0.0.1-x86_64.iso vai aparecer na mesma pasta. Opcional: confira o SHA256 do ISO final:
2086572e504d6e52f43388aff30b005b1df3ea007c538e431d694d64c155a199
